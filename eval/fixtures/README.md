# Detector test fixtures

Images used by `tests/detect-image.test.ts` and `npm run eval:detect`. Expected verdicts are in `images.json`.

| Files | Origin |
| --- | --- |
| `c2pa-valid-no-ai.jpg`, `c2pa-data-changed.jpg`, `c2pa-bad-signature.jpg`, `c2pa-photoshop-generative-fill.jpg`, `c2pa-remote-manifest.jpg` | Copied from the [c2pa-rs](https://github.com/contentauth/c2pa-rs) test fixtures (`CA.jpg`, `XCA.jpg`, `E-sig-CA.jpg`, `ocsp.jpg`, `cloud.jpg`). MIT or Apache-2.0. |
| `certs/` | The C2PA project's public **test** signing certificate and test root, from c2pa-rs (MIT or Apache-2.0). Test-only: never trusted in production. |
| `c2pa-ai-*.jpg/png`, `c2pa-camera-capture.jpg` | Signed by `make-c2pa.mjs` with the test certificate. |
| Everything else | Synthetic images generated by `make_fixtures.py` (Pillow). |

To regenerate the images, run `python3 make_fixtures.py`, then `node make-c2pa.mjs`, from this folder. Afterwards delete the intermediate `images/base.jpg`.

The C2PA Trust List embedded in `src/lib/detect/trust-list.ts` is © C2PA, CC BY 4.0. Refresh it with `npm run trust-list:update`.
